### 实施期修正（与本文档前文表述冲突时以此为准）

1. **「inspector 不再看到不合格处置入口」的说法不准确**。「不合格处置」入口用 `can('quality.view')`，而该能力**包含 inspector**，所以 inspector 仍然可见且点击为 200。改动前该入口本就对这 3 个角色可见。t3/P0-3b 的真实效果是让**入口可见性与端点能力严格一致**（可见 ⟺ 有能力，看到即非 403），而非缩小可见范围。前文 P0-3 遗留清单里若出现「inspector 撞 403」的表述，请以本条为准。
2. **`permissions.py::_wants_json()` 有一处运行时语义改动**（t4 引入，t6 已 A/B 验证）：新增 `request.method in ('DELETE','PUT','PATCH')`。效果是被拒的 DELETE/PUT/PATCH 由 `302 text/html` 变为 `403 application/json`；匿名请求 401 JSON；GET 侧与有权限调用完全不变；HTML 表单只有 GET/POST，不受影响。符合 AGENTS.md「禁止 JSON API 返回 HTML」。
3. **`production_center.py` 的 docstring 不是乱码**：经字节级核查为干净 UTF-8，控制台按 GBK 渲染 UTF-8 造成的显示假象。
4. **沙箱环境适配**：本会话 DSH 沙箱禁止 python 写入 `tempfile.mkdtemp()`（mode 0o700）新目录、并禁止子进程管道捕获，导致 `scripts/check_db_bootstrap.py`、`scripts/functional_test.py`、`scripts/smoke_test.py`、`scripts/permission_matrix.py`、`scripts/route_inventory.py` **原生命令在环境层失败**。已新增 `scripts/_sandbox_compat.py`（只放宽临时目录 mode 与子进程输出通道，被测脚本与断言一行未改）：
   `python -B scripts/_sandbox_compat.py scripts/functional_test.py`
   无沙箱限制的环境（开发机/CI/Jenkins）直接跑原生命令即可，无需该层。
