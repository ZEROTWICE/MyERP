## 9. 推送通道说明

| 项 | 实测情况 |
| --- | --- |
| remote 名称 | **`github`**（不是 `origin`）。远端跟踪分支是 **`github/main`** —— `git rev-parse origin/main` 会报 `unknown revision`，**不要据此判断「没推送」** |
| remote URL | `https://github.com/ZEROTWICE/MyERP.git`（HTTPS） |
| 出口网络 | `github.com:443`（HTTPS）**本机常被阻断**；`github.com:22`（SSH）**可用且密钥已登记** |
| HTTPS 推不上去时 | 改用 SSH 目标直推（不需要先加 remote）： |

```powershell
git push git@github.com:ZEROTWICE/MyERP.git main
```

核对远端是否已跟上：

```powershell
git fetch github            # 443 被阻断时可能失败，属预期
git rev-list --left-right --count github/main...HEAD   # "0	0" 即远端 == 本地
```
