## 2. 精确改动

### 2.1 `permission_matrix.py`（真修：伪门禁补失败出口）
现状（已核实）：
```python
:111   if not anon_open:
:112       print('  无')
...
:129   with open('../_permission_matrix.json', 'w', encoding='utf-8') as f:
:130       json.dump(matrix, f, ensure_ascii=False, indent=1)
:131   print('\n完整矩阵已写入 _permission_matrix.json')
:132   return 0
```

改法（两条）：
1. **补失败出口**：`anon_open` 非空 ⇒ 退出非 0。建议在 `:132` 前加：
   ```python
   if anon_open:
       print(f'\n[FAIL] 匿名可访问视图 {len(anon_open)} 个（应为 0）')
       return 1
   return 0
   ```
   > 判据语义不变（仍是「匿名可访问应为 0」），只是**让退出码携带它**。
2. **停止污染仓库根**：`../_permission_matrix.json` 改为
   `test-reports-2026-10/.tmp/<RUN_ID>/_permission_matrix.json`（或加 `--out` 参数，默认写 `.tmp`），
   并保证**写盘失败不再决定退出码**（写盘与判据解耦）。

### 2.2 `smoke_test.py`（写盘污染型：解耦退出码与写盘）
现状：`:186` 无条件写仓库根 `_smoke_results.json` ⇒ 受限环境/permission 变化时**断言全绿也 exit 1**（「狼来了」）。
改法：加 `--no-dump`（或改写到 `.tmp/<RUN_ID>/`），使 **exit code 只反映断言结果**。

### 2.3 报告型（`route_inventory.py:38` / `measure_coverage.py:485`）
**不改逻辑**，但必须：
1. 在两脚本 docstring 顶部显式标注「**报告型：退出码无判据语义，不得进门禁链；消费方应为解析 JSON 的漂移检测**」；
2. 新增/复用解析器 `harness/coverage_drift.py`（可归 TL-03），**以 JSON 为输入产出判据**（而不是看退出码）。
