### 4.1 为什么用树副本

`uat_chains.py` 直接写 `evidence/uat/uat_chains.json`（未经 `_env.save_evidence`，A-58 已登记）⇒ 在真实仓库复跑会**原地覆盖**冻结证据。`harness/w2w3_uatdiff.py` 因此把 `app/ + scripts/ + config.py + app.db + harness/` 复制到 `.tmp/<RUN_ID>/trees/{before,after}` 后各跑一次，并把两次产物用 `save_evidence` 落进本任务 run 目录（真实 evidence 树**零写入**）。

- `tree-after` = 当前工作树副本；`tree-before` = 同一副本**只回退 t7 的 5 处改动**（`mes_service.py` 用 `git show HEAD:` 整文件回退——该文件 t7 前与 HEAD 逐字节相同；其余 3 文件用精确反向替换）。
- **构造自证**（run `w2w3-uatdiff-final`）：`tree-before` 的 t6/t8 标记（`Consumable, ConsumableCategory` / `_reraise_http` ×2 / `task.notes = data.get('notes'` / `errorhandler(HTTPException)`）**全在位**、t7 标记 7 项**全消失**；`tree-after` 全部在位。
