## 1. 根因 A：PG 连接参数泄漏到 SQLite 路径（运行时缺陷，非口径问题）

**现象**：首跑 `ci_gates.py --phase first` ⇒ 8 个 blocking 失败（`check_db_bootstrap` / `run_gates` /
`functional_test` / `permission_matrix` / `coverage_drift` / `chain_count_consistency` /
`negative_matrix` / `check_doc_claims`）。产物留档
`test-reports-2026-10/evidence/harness/ci-run-20261010-085117/ci_gates_first.console.txt`。

**现场 traceback（原文）**：

```
TypeError: 'connect_timeout' is an invalid keyword argument for Connection()
```

**机制**：`adcaf63` 给 `config.py` 加了
`SQLALCHEMY_ENGINE_OPTIONS['connect_args'] = {'connect_timeout': 10, 'application_name': 'myerp'}`。
这两个是 **psycopg2 专有**参数，却被**无条件**施加。门禁 `harness/_env.py:258-263 run_child`
**不设 `DATABASE_URL`** ⇒ app 走 SQLite 回退路径 ⇒ `sqlite3` 的 DBAPI 拒绝该关键字 ⇒
**任何需要启动 app 的门禁步当场崩溃**（`check_db_bootstrap` 报 `bootstrap_accounts 期望 64 实际 None`
即由此派生，不是数据问题）。

**修法（根因，非逐调用点打补丁）**：`config.py` 新增模块级 `_DB_URI` 与 `_engine_options(uri)`，
PG 池化参数仅在 `uri.startswith('postgresql')` 时注入；SQLite 路径只留 `pool_pre_ping` + `pool_recycle`。

| 口径 | 改前 | 改后 |
| --- | --- | --- |
| `DATABASE_URL` 未设 ⇒ `Config.SQLALCHEMY_ENGINE_OPTIONS` | `{pool_size:5, max_overflow:10, pool_timeout:30, pool_recycle:1800, pool_pre_ping:True, connect_args:{connect_timeout:10, application_name:'myerp'}}` | `{pool_pre_ping:True, pool_recycle:1800}` |
| SQLite 路径 `create_app()` + `SELECT 1` | `TypeError`（app 不可用） | `1` |
| PG16 路径 `create_app()` + `SELECT 1` / `count(*) FROM "user"` | `1` / `64` | `1` / `64`（**不变**，功能未退化） |
| `ci_gates --phase first` blocking 失败数 | **8** | **3**（见 §2） |
