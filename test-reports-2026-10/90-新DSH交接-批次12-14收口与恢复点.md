### 5.3 ⚠ `run_gates.py` 的 exit 1 ≠ 回归 ≠ 绿灯（交接时现场读原文）

```
"exit_code_semantics": { "code": 1, "reasons": ["probe_unexpected=1"],
  "rule": "exit 0 ⇔ summary['fail']==0 ∧ summary['probe_unexpected']==0 ∧ …" }
"summary": { "total": 6, "pass": 5, "fail": 0, "probe_only": 1, "probe_unexpected": 1 }
```

机理：`route_inventory_native_probe` 钉死 `expected_exit_code=1`，其前提是「`mkdtemp(0o700)` 不可写 ⇒ `PermissionError`」；在**放宽的沙箱**下 `mkdtemp` 可写 ⇒ 实测 0 ⇒ 判 `unexpected`。
⇒ **在 `danger-full-access` 下该 exit 1 是恒定的**。判定健康看 `summary.fail == 0`（上述样本 pass=5/fail=0）。**不要把 exit 1 当回归去「修」，也不要当绿灯去放行。**
